Searching & sorting

File list, search and filters

By default, the right list shows the selected folder’s direct children. The map also shows deeper levels.

Find files

  1. Enter a name, part of a path or an extension such as .zip. Patterns such as *.pdf are also supported.
  2. Use the icon immediately beside the search field. Filter & Sort expands underneath without covering the list.
  3. Enable Include subfolders to search deeper levels. Clear the query and inspect active filters if expected entries are missing.

Filter and sort

  • Show: all entries, files only or folders only.
  • Type: for example archives, documents, images, audio or video.
  • Sort: size, name or type, ascending or descending.
  • Folders first: enabled by default; folders precede files.
  • The list loads more entries as you scroll, without page controls.

Why the list may differ from the map

A file in a subfolder is already represented in the recursive map but appears in the direct list only after opening that folder or enabling Include subfolders. Search and list filters change neither source files nor the original scan total. Recycle-bin and system-content visibility switches apply to map, tree and list together.
